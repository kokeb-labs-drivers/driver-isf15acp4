Detailed Description

ISF15ACP4 driver: the one header to include.

Copyright
Copyright (c) 2026 The driver-isf15acp4 authors. SPDX-License-Identifier: MIT

isf15acp4::ISF15ACP4<Port> drives one NKK ISF15ACP4 frameless OLED pushbutton through a platform port you write (see isf15acp4_spi_interface.hpp): the SSD1331-class display controller over write-only SPI, the 15 V OLED supply through an enable pin, and the SPST switch through a pin read. The driver has no platform code, allocates nothing, throws nothing, takes no lock and is not thread-safe: give each object one owner, or guard it with one mutex.

The controller cannot be read: the driver knows only what it sent (docs/contract.md).
