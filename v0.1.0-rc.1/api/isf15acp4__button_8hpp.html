Detailed Description

The switch debouncer: a time-injected state machine with press, release, long-press and repeat events.

The switch is an SPST normally-open contact (NKK sheet E4: "Leave actuator: 1 - 2 OFF, push actuator: 1 - 2 ON"). The sheet gives no bounce time, so the debounce time is ButtonConfig's knob. ButtonDebouncer has no port, no clock and no I/O: the caller passes the sampled level and a millisecond timestamp. All time arithmetic is unsigned subtraction, so a wrapping 32-bit counter is handled.
