Detailed Description

Public types of the ISF15ACP4 driver: errors, Result<T>, the display and button configuration, the module variants and the colour helpers.

Everything here is plain data with no platform dependency. Config{} describes the ISF15ACP4 (96 x 64 pixels) with the controller settings the module is driven with; PresetFor() gives the two smaller modules of the family. The controller has no readable register, so none of these values can be confirmed from the chip: they are what the driver sends (docs/contract.md). The start-up values of each module are the ones in NKK's application notes for the OLED Color SmartDisplay: Table 1 (ISC15ANP4), Table 2 (ISC01P) and Table 3 (ISF15ACP4), steps 4.1 to 4.18. NKK Note 1: changing those set-up values may damage the OLED module. None has been tried on a panel here.
