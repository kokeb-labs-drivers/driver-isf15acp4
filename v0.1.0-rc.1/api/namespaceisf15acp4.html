◆ kContinuousWord

constexpr bool isf15acp4::kContinuousWord = false
inlineconstexpr

false: the datasheet sets no limit on idle SCK time between the bytes of one transfer; D/C# is sampled on every eighth clock.

◆ kMinCsHighNs

constexpr uint32_t isf15acp4::kMinCsHighNs = 150
inlineconstexpr

Shortest time CS# stays high between two transfers: the datasheet gives none, so one SCLK period (tcycle) is used; not verified on hardware.

◆ kSpiMode

constexpr uint8_t isf15acp4::kSpiMode = 0
inlineconstexpr

SPI mode the driver is tested with: CPOL 0, CPHA 0. Data is taken on the SCLK rising edge, so mode 3 also works (Figure 39).
