Detailed Description

Optional ESP-IDF layer: a Config built from the CONFIG_ISF15ACP4_* Kconfig options.

Copyright
Copyright (c) 2026 The driver-isf15acp4 authors. SPDX-License-Identifier: MIT

Include this header only where you want menuconfig to choose the defaults; the driver never includes it and no driver signature depends on it. Under ESP-IDF the values come from sdkconfig.h. Without Kconfig every option falls back to the default of Config{}, so KconfigDefaults() equals Config{}.

Kconfig writes a bool option set to "n" as an absent macro, so an absent CONFIG_ISF15ACP4_RED_ON_SEGMENT_A or CONFIG_ISF15ACP4_BUTTON_ACTIVE_LOW is read as off only when the option menu is present (CONFIG_ISF15ACP4); without the menu the defaults stay on.

One configuration per program: the inline function below depends on the CONFIG_ macros, so every translation unit of one program must see the same values (ESP-IDF has one sdkconfig.h per build; each host test is its own program). No driver or library header includes this one (handbook KB-CPP20-018).
