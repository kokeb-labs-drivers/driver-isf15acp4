◆ Error

enum class isf15acp4::Error : uint8_t
strong

Why a call failed. Every call of the driver returns one of these in its Result.

Values 0 to 9 are the shared base set; chip-specific values start at 16. [[nodiscard]] on the type: a function that returns a bare Error cannot have it ignored either (KB-CPP20-037).

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() has not succeeded, or Deinitialize() ran since.

InvalidArgument 

An argument or a Config field is out of range; nothing was sent.

Bus 

A port hook returned false (a transfer or a pin write).

Timeout 

Not returned by this driver: nothing the driver waits for is observable.

DeviceIdMismatch 

Not returned by this driver: the controller has no ID and cannot answer.

Crc 

Not returned by this driver: the serial interface has no checksum.

Busy 

Not returned by this driver: every wait blocks until it has elapsed.

DeviceFault 

Not returned by this driver: the controller reports no fault.

Unsupported 

The port lacks the optional hook this call needs (switch, clock) or the pixel format does not allow the call.

ScrollActive 

A RAM, drawing or setup call while scrolling is on (Deactivate first).

ScrollNotSet 

ActivateScroll() before SetupScroll() succeeded.

SupplyOff 

The call needs the OLED supply on (raw display-on).

Locked 

The controller is command-locked by SetCommandLock(true).
